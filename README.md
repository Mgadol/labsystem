# Лабораторийн удирдлагын систем

Нүүрсний лабораторийн ажлыг дээж бүртгэхээс эхлээд баталгаажсан үр дүн,
архивлалт хүртэл нэг системд удирдана. Хэн, хэзээ, ямар тоног төхөөрөмжөөр
хийсэн нь мөр бүрт үлдэнэ.

Бодит хэрэглээнд өдөр бүр ажиллаж байгаа систем.

---

## Юу хийдэг вэ

### Шинжилгээний бүрэн урсгал

```
Бүртгэл  →  Хүлээн авалт  →  Дээж бэлтгэл  →  Хэмжилт  →  Баталгаажуулалт  →  Архив
геологич     лаборант        бэлтгэгч         химич       ахлах химич         систем
```

Өмнөх алхам дуусаагүй бол дараагийнх нээгдэхгүй тул ажил алгасагдах,
давхардах боломжгүй. Ажлын дугаар (`6175-20260807` хэлбэрээр) автоматаар
үүсч, давхардахгүй.

### Шинжилгээний үзүүлэлт

| Үзүүлэлт | Тэмдэглэгээ | Тооцоо |
|---|---|---|
| Нийт чийг | Mt | жингээс |
| Дотоод чийг | Mad | автомат |
| Үнслэг | Aad | автомат |
| Дэгдэмхий бодис | Vad | автомат |
| Тогтмол нүүрстөрөгч | FCad | автомат (100 − Mad − Aad − Vad) |
| Хүхэр | Std | хэмжилтээр |
| Илчлэг | Qb,ad | калориметрээс |
| Барьцалдах индекс | G | автомат |
| Чөлөөт хөөлтийн зэрэг | FSI | хэмжилтээр |

Хуурай суурь (Adb, Vdb) болон хуурай үнсгүй суурь (Vdaf) руу хөрвүүлэлт
автоматаар хийгдэнэ.

### Хэмжилтийн хуудас

Excel шиг хүснэгт, гэхдээ алдаанаас хамгаалагдсан:

- Сум, Tab, Enter товчоор шилжинэ — хулгай хүрэлгүй бөглөнө
- Нүд орхих бүрт **автоматаар хадгална**, хадгалах товч байхгүй
- Утга орсон нүд түгжигдэж, санамсаргүй өөрчлөгдөхөөс хамгаална
- Химич өөрийн хийж буй шинжилгээгээ л дэлгэцэнд гаргана
- Хэд хэдэн ажлын дээжийг нэг хүснэгтэд нэгтгэн хэмжинэ (багц ажил)

### Чанарын хяналт

- **Зэрэгцээ ба давтан хэмжилт** — үзүүлэлт тус бүрт зөвшөөрөгдөх зөрүү,
  мөрдөх стандарт тохируулна. Хүлцэлд багтсан хэмжилтүүдийн дундаж эцсийн
  үр дүн болно; хэтэрсэн нь өнгөөр илэрнэ
- **CRM баталгаат дээж** — гэрчилгээт утгатай зөрүү, хувиар харьцуулах,
  гэрчилгээний ±U тодорхойгүй байдлыг харгалзана
- **Дотоод QC хөтөлбөр** — тогтмол давтамжтай хяналтын дээж

### Тоног төхөөрөмж

Паспорт (PDF, зураг), калибровкын хугацаа ба сануулга, засварын түүх
(компани, зардал, үр дүн), өдөр/долоо хоног/сар тутмын шалгалт, жин ба
калориметрийн тусгай шалгалт, ашиглалтын бүртгэл, ажилтан тус бүрийн
ажиллуулах эрх.

### Орчны хяналт

Өрөө тус бүрийн температур, чийгшлийг ажлын эхлэл, төгсгөлд бүртгэнэ.
Тогтоосон хязгаараас хэтэрсэн заалт тод ялгарна. Excel-рүү гаргана.

### Тайлан ба хяналт

Долоо хоног, сар, улирлаар график ба олон хуудаст Excel тайлан. Нүүр
хуудсанд өнөөдрийн байдал: хүлээгдэж байгаа ажил, хугацаа дөхсөн
калибровк, нээлттэй засвар.

### Хэрэглэгчийн эрх

Долоон дүр: `admin`, `senior` (ахлах химич), `staff` (химич),
`preparer` (дээж бэлтгэгч), `geologist`, `bayjuulach` (баяжуулагч),
`guest` (зочин). Үүн дээр нэмж хүн тус бүрт баталгаажуулах, тайлан
гаргах, үр дүн харах, экспортлох, дахин нээх эрхийг тусад нь олгоно.

Захиалагчид үр дүн үзүүлэх шаардлагатай бол 24 цагийн хугацаатай
түр хандалтын линк үүсгэнэ.

## Техникийн шийдэл

| | |
|---|---|
| Backend | Python 3.10+, Flask, waitress |
| Мэдээллийн сан | SQLite (WAL) — тусдаа сервер, лиценз шаардахгүй |
| Frontend | Jinja2, энгийн JavaScript (framework-гүй) |
| Экспорт | Excel (openpyxl) |
| Хэрэглэгчийн тал | Вэб хөтөч — суулгах программгүй |
| Хэл | Монгол, англи |

### Аюулгүй байдал

- Нууц үг: werkzeug (scrypt)
- Нэвтрэх оролдлогын хязгаарлалт (IP тус бүрээр)
- Сешн күүки: HttpOnly, SameSite; HTTPS үед Secure
- Суулгац бүр өөрийн нууц түлхүүртэй, анхны админд санамсаргүй нууц үг
- Үр дүн үзсэн хандалт бүртгэгдэнэ

## Суулгах

Дэлгэрэнгүйг **[INSTALL.md](INSTALL.md)**-ээс үзнэ үү.

```bash
git clone -b main https://github.com/Mgadol/labsystem /opt/labsystem
cd /opt/labsystem
python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python3 app.py
```

Анхны админы нууц үг консол дээр хэвлэгдэнэ.

## Шинэчлэх

```bash
cd /opt/labsystem && git pull && sudo systemctl restart labsystem
venv/bin/python3 tools/healthcheck.py
```

Мэдээллийн сангийн шинэ хүснэгт, багана автоматаар нэмэгдэнэ.

> Засварыг сервер дээр шууд хийж болохгүй — дараагийн `git pull` дарж
> устгана. Оношилгоог серверт хийж болох ч засвар нь гитээс явна.

## Хэрэгслүүд

| Скрипт | Зориулалт |
|---|---|
| `tools/healthcheck.py` | Суулгацын бүрэн бүтэн байдлыг шалгах (шинэчлэлтийн дараа) |
| `tools/report_check.py` | Тайлангийн тоо хэрхэн бүрдэж байгааг задлан харах |
| `tools/recalc.py` | Хадгалагдсан тооцоог дахин бодох |
| `tools/check_sample.py` | Тодорхой дээжийн бүх утгыг шалгах |
| `tools/job_status.py` | Ажлын төлөвийг шалгах |

## Нөөцлөлт

Систем өдөр бүр автоматаар нөөц хуулбар үүсгэж, 14 хоногоос хуучныг
цэвэрлэнэ (SQLite-ийн online backup API — ажиллаж байгаа сан дээр
аюулгүй). Тохиргоо → Нөөцлөлт хэсгээс татаж авч болно.

Хамгийн чухал файлууд: `instance/lab.db`, `instance/settings.json`,
`static/uploads/`.
