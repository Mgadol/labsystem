# Лабораторийн тоног төхөөрөмжийн удирдлагын систем

## Суулгах заавар (Windows)

### 1. Python суулгах
https://python.org/downloads → "Add Python to PATH" чекбокс дээр чагтаж суулга

### 2. Төслийн хавтсыг задла
`labsystem` хавтсыг татаж аваад C:\Users\[таны нэр]\Documents\ дотор хадгал

### 3. Terminal нээх
Windows товч + R → `cmd` бичиж Enter дар

### 4. Хавтас руу орох
```
cd C:\Users\[таны нэр]\Documents\labsystem
```

### 5. Шаардлагатай сангуудыг суулгах
```
pip install -r requirements.txt
```

### 6. Програмыг ажиллуулах
```
python app.py
```

### 7. Браузераар нэвтрэх
- Нэг компьютераас: http://localhost:5000
- Сүлжээнд байгаа бусад утас/компьютераас: http://[таны компьютерийн IP]:5000

## Анхны нэвтрэлт
- ID: **ADMIN**
- Нууц үг: **admin123**
- ⚠️ Нэвтэрсний дараа нууц үгийг заавал солино уу!

## Компьютерийн IP олох
```
ipconfig
```
`IPv4 Address` гэж харагдах тоог ав (жишээ: 192.168.1.105)

Ажилтнууд утаснаасаа: http://192.168.1.105:5000 гэж нэвтэрнэ

## Гаднаас нэвтрэх (интернэтээр)
ngrok суулгаж ашиглана:
1. https://ngrok.com бүртгүүл
2. `pip install ngrok`
3. `ngrok http 5000`
4. Гарч ирсэн https URL-ийг ажилтнуудад хуваалц

## Дараа нэмж болох
- Систем автоматаар эхлэх (Windows startup)
- SSL certificate (HTTPS)
- Нөөцлөлт (backup)
