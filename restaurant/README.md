# 🍽 Хүрэншанд Ресторан — Дижитал меню апп

Лабораторийн системээс **бүрэн тусдаа**, бие даасан Flask апп.
Өөрийн database (`instance/restaurant.db`), өөрийн дизайнтай.

## Ажиллуулах

```bash
pip install flask pillow
python app.py
```

| Хаяг | Тайлбар |
|---|---|
| http://localhost:5001 | Зочдод харагдах меню (нэвтрэлт шаардахгүй) |
| http://localhost:5001/admin | Меню удирдлага |

Админ нууц үг: `resto123` (солих бол `RESTO_ADMIN_PASS` орчны хувьсагч тохируулна)

## Онцлог

- **50 хоолны бэлэн меню** — 10 ангилал: зууш, салат, шөл, үндсэн хоол,
  үндэсний хоол, гриль & BBQ, гарнир, амттан, ундаа, кофе & цай
- Хоол бүр мэргэжлийн тайлбар, найрлага, порц, илчлэг, үнэтэй
- Тэмдэглэгээ: ⭐ Тогоочийн санал · ✨ Шинэ · 🌶 Халуун ногоотой · 🌿 Цагаан хоолтон
- **Зочдын апп**: тогоочийн саналын карусель, ангилалын шүүлтүүр (scroll-spy),
  хайлт, хоолны дэлгэрэнгүй bottom-sheet
- **Админ**: хоол нэмэх/засах/түр хаах/устгах, зураг оруулах, шүүлт, статистик

Эхний ажиллуулалтад 50 хоолны меню автоматаар үүснэ.
Дараа нь бүх өөрчлөлт админ хэсгээс хийгдэнэ.
